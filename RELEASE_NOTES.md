# PlayBuilder v0.0.7

## New: Safe 1G1R recommendation preview

PlayBuilder can now turn duplicate release groups from the archive scan into a clear one-game-one-region recommendation plan.

### Included

- New **1G1R Rules** screen linked from the dashboard.
- Default preference order: USA → World → Europe → Australia → United Kingdom → Canada.
- Move region priorities up or down and watch recommendations update immediately.
- Recommended English and North America-first presets.
- Optional preferences for English-friendly copies, standard retail releases, and newer revisions.
- A recommended file for every detected duplicate group.
- Clear explanations for why each copy was selected.
- Fallback warnings when none of the preferred regions are available.
- Expandable lists showing the alternate copies that remain safely in the original archive.
- Summary totals for confident choices, fallbacks, and extra versions.

## Safety

This release is still read-only. It does not copy, move, rename, convert, or delete game files. The 1G1R screen is a recommendation preview only.
