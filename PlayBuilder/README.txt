PlayBuilder v0.0.8 Rules Patch

Copy the Components, Models, and Services folders into your CURRENT PlayBuilder project and choose Replace when prompted.

This patch intentionally contains only the four changed rules files, so it will not overwrite your new Program.cs, SQLite packages, Data folder, or database work.

Changes:
- Fixes crashes while reordering language and region priorities.
- Reorders by stable item identity instead of a rendered list index.
- Adds 1G1R All Games mode.
- Adds 1G1R English Only mode.
- Adds configurable language priority.
- Adds English-first, Japanese-first, and Europe-first presets.
- Shows selected language and region in each recommendation.
